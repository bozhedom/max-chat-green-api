# MAX Chat

Веб-клиент для переписки в мессенджере MAX через [GREEN-API](https://green-api.com/max). Пользователь вводит данные инстанса, создаёт чат по номеру телефона, отправляет текстовые сообщения и видит ответы собеседника в чате.

Демо: https://bozhedom.github.io/max-chat-green-api/

## Возможности

- Вход по реквизитам инстанса GREEN-API (`idInstance`, `apiTokenInstance`, `apiUrl`) с проверкой состояния инстанса
- Создание чата по номеру телефона получателя
- Отправка текстовых сообщений методом [SendMessage](https://green-api.com/v3/docs/api/sending/SendMessage/)
- Получение входящих сообщений и статусов доставки по [HTTP API](https://green-api.com/v3/docs/api/receiving/technology-http-api/) через ReceiveNotification и DeleteNotification
- Список чатов с последним сообщением, временем и счётчиком непрочитанных
- Сохранение сессии и истории переписки в localStorage

## Требования

- Node.js 20 или новее
- Инстанс GREEN-API для MAX в состоянии `authorized`

## Настройка инстанса GREEN-API

Чтобы приложение получало входящие сообщения, в личном кабинете GREEN-API (или методом `SetSettings`) для инстанса нужно выставить:

| Параметр          | Значение |
| ----------------- | -------- |
| `webhookUrl`      | пустое   |
| `incomingWebhook` | `yes`    |
| `outgoingWebhook` | `yes`    |
| `stateWebhook`    | `yes`    |

Пустой `webhookUrl` означает, что уведомления складываются в очередь инстанса, а клиент забирает их методом `ReceiveNotification`.

## Как пользоваться

1. Откройте приложение и введите `idInstance` и `apiTokenInstance` из личного кабинета GREEN-API. Поле `apiUrl` заполнено значением по умолчанию `https://api.green-api.com`, замените его, если в кабинете указан другой адрес.
2. Введите номер телефона получателя в формате `79991234567` и нажмите `+`. Чат появится в списке слева.
3. Напишите сообщение и отправьте его клавишей Enter, Shift+Enter переносит строку.
4. Ответ собеседника из приложения MAX появится в чате автоматически, без перезагрузки страницы.

Реквизиты инстанса хранятся только в браузере пользователя, запросы уходят напрямую в GREEN-API без промежуточного сервера.

## Структура проекта

```
src/
├── app/                      сборка приложения
├── features/
│   ├── session/              вход по реквизитам инстанса и хранение сессии
│   │   ├── model/            useSession
│   │   └── ui/               LoginScreen
│   └── chat/                 переписка
│       ├── model/            состояние чатов, приём уведомлений, отправка
│       └── ui/               список чатов, лента сообщений, форма ввода
├── shared/
│   ├── api/                  типизированный клиент GREEN-API
│   ├── lib/                  телефоны, даты, localStorage
│   └── ui/                   переиспользуемые элементы интерфейса
└── styles/                   токены оформления и глобальные стили
```

Каждый компонент лежит в своей папке вместе со стилями и файлом реэкспорта.

Состояние чатов описано чистым редьюсером в `features/chat/model/chatsReducer.ts`, разбор уведомлений вынесен в `notificationMapper.ts`, цикл опроса очереди уведомлений в `useNotificationStream.ts`.

Исходящие сообщения адресуются по идентификатору вида `79991234567@c.us`, а входящие приходят с числовым `chatId` MAX. Поэтому чат ищется по номеру телефона из поля `senderPhoneNumber`, после чего к нему привязывается `chatId` из уведомления.
